# Civitas Alpha 0.3.0 — сборка и установка (Forge 1.21.1)

Alpha 0.3.0 находится в разработке. Здесь добавляется настоящий склад с 27 слотами, сохраняемым инвентарём и отдельным экраном. Не устанавливай эту версию в основной мир до успешной сборки и ручной проверки.

## Требования

- Minecraft Java Edition 1.21.1 с Forge 52.1.20.
- 64-разрядный JDK 21.
- Интернет для загрузки Gradle и зависимостей.

Проверь Java в PowerShell:

```powershell
java -version
```

## Скачать сборку

Открой GitHub Actions: https://github.com/S1nuso1d/Civitas/actions

Выбирай только последний запуск с результатом **success** и скачивай артефакт `civitas-0.3.0-forge-1.21.1`, если он опубликован. Если последний запуск завершился ошибкой или артефакта нет, сборка ещё не готова.

## Собрать из исходников

1. Скачай ZIP: https://github.com/S1nuso1d/Civitas/archive/refs/heads/main.zip
2. Распакуй полностью, например в `C:\Projects\Civitas`.
3. Открой PowerShell в папке проекта и запусти:

```powershell
.\tools\gradle-run.ps1 build
```

Или запусти `build.bat`. Дождись `BUILD SUCCESSFUL`. Ожидаемый файл: `build\libs\civitas-0.3.0.jar`.

## Установка в TLauncher

1. Закрой Minecraft.
2. Открой игровую папку выбранного профиля Forge 1.21.1 и папку `mods`.
3. Удали/перемести старые JAR Civitas, чтобы не загружать две версии одновременно.
4. Скопируй туда `civitas-0.3.0.jar`.
5. Запусти профиль Forge 1.21.1.

## Проверка в тестовом мире

Сначала создай резервную копию мира. Для начала используй:

```text
/civitas help
/civitas found Моя деревня
/civitas status
```

Возьми склад во вкладке «Функциональные блоки», размести его и нажми правой кнопкой. После открытия попробуй перенести предметы между инвентарём игрока и складом обычным перетаскиванием и Shift-click. Затем закрой и снова открой интерфейс, выйди из мира и зайди снова — содержимое должно сохраниться.

В существующем мире ресурсы из виртуального склада Alpha 0.2 переносятся в свободные слоты физического склада при открытии. Переносится только то, что реально помещается; остаток должен сохраниться в старом хранилище. Команды `/civitas deposit` и `/civitas withdraw` пока управляют именно виртуальным хранилищем.

## Что считается подтверждённым

- Успешная сборка — только если последний GitHub Actions run имеет статус success или локальная Gradle-сборка завершилась `BUILD SUCCESSFUL`.
- Поведение в Minecraft — только после ручного теста в Forge 1.21.1.
- Не используй непроверенный JAR в основном мире.
