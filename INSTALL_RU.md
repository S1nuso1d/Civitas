# Civitas Alpha 0.4.0 — сборка и установка (Forge 1.21.1)

Alpha 0.4.0 добавляет автоматически создаваемую стартовую деревню и первого физически работающего лесоруба. Gradle-сборка прошла успешно в GitHub Actions: https://github.com/S1nuso1d/Civitas/actions/runs/40600446312. Ручной запуск Minecraft и тест сохранения мира нужно выполнить отдельно.

## Требования

- Minecraft Java Edition 1.21.1 с Forge 52.1.20.
- 64-разрядный JDK 21.
- Интернет для загрузки Gradle и зависимостей.

Проверка Java:

```powershell
java -version
```

## Скачать JAR

Открой https://github.com/S1nuso1d/Civitas/actions и выбери последний запуск со статусом **success**. В разделе Artifacts скачай `civitas-0.4.0-forge-1.21.1`, если артефакт опубликован. Не используй артефакт от старого коммита, если после него в проект внесены изменения.

## Собрать из исходников

1. Скачай ZIP: https://github.com/S1nuso1d/Civitas/archive/refs/heads/main.zip
2. Распакуй полностью, например в `C:\Projects\Civitas`.
3. Открой PowerShell в корне проекта и выполни:

```powershell
.\tools\gradle-run.ps1 build
```

Или запусти `build.bat`. После `BUILD SUCCESSFUL` ожидаемый файл: `build\libs\civitas-0.4.0.jar`.

## Установка в TLauncher

1. Закрой Minecraft.
2. Открой папку `mods` профиля Forge 1.21.1.
3. Удали старые JAR Civitas, чтобы не загрузить две версии.
4. Скопируй `civitas-0.4.0.jar` в `mods`.
5. Запусти Minecraft 1.21.1 с Forge 52.1.20.

## Как работает стартовая деревня

При первом входе мод создаёт деревню в Надземном мире: четыре дома, кровати, рабочие блоки, дорожки, освещение, четыре обычных жителя и центральный склад с начальными запасами. Координаты деревни сохраняются в данных мира, поэтому она не создаётся повторно при следующем входе. Новые игроки тоже появляются там; после смерти игрок возвращается в деревню.

Генератор ищет подходящий относительно ровный участок около мирового спавна. Если подходящий участок не найден, используется запасной вариант около мирового спавна. В последнем случае ландшафт может быть изменён сильнее, поэтому в существующем мире сначала сделай резервную копию.

## Лесоруб

Один житель получает имя «Лесоруб Civitas». Он ищет рядом древесные блоки с листьями, подходит к ним, рубит блоки с задержкой, переносит до восьми брёвен и возвращается к центральному складу. Если склад заполнен, груз остаётся у работника. Если рядом нет деревьев, работник ждёт.

## Проверка в тестовом мире

- Создай новый мир и убедись, что появляешься рядом с центральным складом.
- Проверь наличие домов и жителей.
- Открой склад, перемести предметы, закрой и снова открой его.
- Выйди из мира и зайди снова: деревня не должна строиться второй раз.
- Умри в Надземном мире и проверь возврат в деревню.
- Если используешь старое сохранение, сделай резервную копию до первого входа.

Сборка подтверждает компиляцию, но не гарантирует, что все эти проверки уже выполнены вручную.
