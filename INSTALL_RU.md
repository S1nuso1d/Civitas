# Civitas Alpha 0.2.6 — сборка и установка (Forge 1.21.1)

В версии 0.2.6 добавлены действия в GUI и размещаемый блок «Склад поселения». Открой Кодекс цивилизации или размести склад и нажми по нему. После успешной сборки JAR будет `build\\libs\\civitas-0.2.6.jar`.

## Что исправлено

- `build.bat` и `run-client.bat` больше не передают PowerShell-скрипту абсолютный путь, который Windows мог некорректно разобрать.
- Скрипты сначала переходят в корневую папку проекта и запускают `tools\gradle-run.ps1` по относительному пути.
- `.bat`-файлы записаны с Windows CRLF-переносами; сообщения в них и PowerShell-скрипте используют ASCII, чтобы исключить проблемы вывода из-за кодировки консоли.
- Сохранено исправление `pack.mcmeta` из 0.2.2 (`pack_format: 34` для Minecraft 1.21–1.21.1).

## 1. Требования

- Minecraft Java Edition 1.21.1 с Forge 52.x.
- 64-разрядный JDK 21. Проверь в PowerShell командой `java -version`.
- Интернет для первой загрузки Gradle и зависимостей Minecraft/Forge.

## 2. Собрать JAR

1. Распакуй ZIP полностью, например в `C:\Projects\Civitas-0.2.5`. Не запускай `.bat` прямо из архива.
2. Открой папку `Civitas`, где находятся `build.bat`, `build.gradle` и папка `tools`.
3. Дважды щёлкни `build.bat`.
4. Дождись `BUILD SUCCESSFUL`. Готовый JAR должен быть здесь: `build\libs\civitas-0.2.5.jar`.

Gradle сохраняется в `%LOCALAPPDATA%\CivitasBuildTools`; если версия 8.8 уже скачана, повторно загружать её не требуется.

### Если запуск .bat снова выдаёт ошибку

Открой PowerShell именно в папке `Civitas` (Shift + правая кнопка мыши → открыть PowerShell/Terminal здесь) и выполни напрямую:

```powershell
.\tools\gradle-run.ps1 build
```

Если эта команда работает, а `build.bat` — нет, пришли полный вывод и проверь, что используешь архив 0.2.5 и извлёк его в отдельную папку, а не поверх старой версии.

## 3. Установить в TLauncher

1. Закрой Minecraft.
2. Открой папку игры именно профиля Forge 1.21.1. Стандартный путь — `%appdata%\.minecraft`; при отдельной игровой папке профиля используй её.
3. В `mods` удали/перенеси старые `civitas-0.2.3.jar`, `civitas-0.2.4.jar` и `civitas-0.2.5.jar`, чтобы не загружать несколько версий одновременно.
4. Скопируй `build\libs\civitas-0.2.5.jar` в `mods`.
5. Запусти профиль Forge 1.21.1. Проверь предупреждения при загрузке и меню Mods.

## 4. Проверить команды в новом тестовом мире

```text
/civitas help
/civitas found Моя_деревня
/civitas status
/civitas storage
```

Для теста склада возьми 16 обычных дубовых брёвен в основную руку:

```text
/civitas deposit 16
/civitas storage
/civitas withdraw minecraft:oak_log 8
```

## Статус проверки

Архив, JSON-ресурсы и формат Windows-скриптов проверены статически. Полная компиляция ForgeGradle и запуск Minecraft в этой среде не выполнялись. JAR не включён в ZIP: его нужно собрать на Windows командой `build.bat`.
