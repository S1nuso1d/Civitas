# Civitas Alpha 0.2.7 — сборка и установка (Forge 1.21.1)

Civitas — мод о развитии поселения в Minecraft. В Alpha 0.2.7 доступны сохраняемая модель поселения, панель управления через Кодекс цивилизации и размещаемый блок «Склад поселения». Блок открывает панель, но пока не является настоящим контейнером со слотами.

## 1. Требования

- Minecraft Java Edition 1.21.1 с Forge 52.1.20.
- 64-разрядный JDK 21.
- Интернет для первой загрузки Gradle и зависимостей Minecraft/Forge.

Проверь Java в PowerShell:

```powershell
java -version
```

## 2. Скачать готовую CI-сборку

Последняя подтверждённая сборка Alpha 0.2.7 была успешно собрана GitHub Actions. Открой страницу запуска workflow:

https://github.com/S1nuso1d/Civitas/actions/runs/40598447075

В разделе **Artifacts** скачай архив `civitas-0.2.7-forge-1.21.1` и извлеки из него JAR. Артефакт временный и хранится до 25 января 2027 года; последующие сборки будут иметь собственные страницы Actions.

## 3. Собрать из исходников на Windows

1. Скачай ZIP репозитория: https://github.com/S1nuso1d/Civitas/archive/refs/heads/main.zip
2. Распакуй архив полностью, например в `C:\\Projects\\Civitas`. Не запускай скрипты прямо из ZIP.
3. Открой папку `Civitas`, где находятся `build.bat`, `build.gradle` и папка `tools`.
4. Дважды щёлкни `build.bat` и дождись сообщения `BUILD SUCCESSFUL`.
5. Ожидаемый файл: `build\\libs\\civitas-0.2.7.jar`.

Если запуск BAT-файла не сработал, открой PowerShell в корне проекта и выполни:

```powershell
.\tools\gradle-run.ps1 build
```

Если команда завершилась ошибкой, сохрани полный текст ошибки: не считай JAR готовым, пока сборка не завершилась успешно.

## 4. Установить в TLauncher

1. Закрой Minecraft.
2. Открой папку игры профиля Forge 1.21.1. Обычно это `%appdata%\\.minecraft`; если у профиля отдельная игровая папка, используй её.
3. В папке `mods` удали или перемести старые версии Civitas, чтобы не загружать несколько JAR одновременно.
4. Скопируй `civitas-0.2.7.jar` в `mods`.
5. Запусти профиль Forge 1.21.1 и проверь меню Mods.

## 5. Проверка в тестовом мире

Сначала создай резервную копию важного мира. Затем выполни:

```text
/civitas help
/civitas found Моя деревня
/civitas status
/civitas storage
```

Возьми обычные дубовые брёвна в основную руку и проверь виртуальный склад:

```text
/civitas deposit 16
/civitas storage
/civitas withdraw minecraft:oak_log 8
```

Кодекс цивилизации открывает панель управления. Блок «Склад поселения» можно найти в творческом инвентаре во вкладке «Функциональные блоки»; при нажатии он также открывает панель.
