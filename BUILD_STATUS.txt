Civitas Alpha 0.29.0 — Claimed Territory Protection
Target: Minecraft Java Edition 1.21.1 + Forge 52.1.20 + Java 21

Added:
- Non-owners cannot break/place blocks or right-click blocks in claimed overworld chunks; the settlement owner retains access.
- Building validation checks every column in the rotated footprint against influence and claimed-chunk boundaries.
- Automatic building sites use the same validation as manual sites before resource reservation or vegetation clearing.
- Clearance uses the rotated footprint dimensions.
- Fixed the ChunkPos import that caused compilation errors in Alpha 0.28.0.

Known limitations:
- Protection does not currently cancel explosions, natural updates, mob changes, or changes made by other mods.
- The world still has one player settlement; rival territory ownership is not implemented.
- Manual multiplayer gameplay testing has not been performed.

Validation:
- The exact Alpha 0.29.0 commit has not yet been verified with a local build, tests, or JAR packaging.
- Check GitHub Actions status before treating this release as build-verified.
