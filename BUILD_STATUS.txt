Civitas Alpha 0.4.2 — build status
Target: Minecraft Java Edition 1.21.1 + Forge 52.1.20 + Java 21

Implemented in source:
- Persistent starter village near the Overworld spawn; world spawn is set to the village square.
- First-time login and respawn redirect players to the village, including respawn from other dimensions.
- Four houses, beds, job-site blocks, paths, lantern posts, bell, vanilla villagers and starter resources in the physical warehouse.
- Village location and generation flag are stored in CivitasSavedData.
- A villager is assigned a persistent lumberjack role, including migration for older worlds.
- Lumberjack searches nearby tree logs with leaves, navigates to the tree, chops with a short delay, carries up to eight logs, returns to the warehouse and deposits into physical slots.
- If the warehouse is missing/full, carried logs remain with the worker until delivery can resume.
- Alpha 0.4.1 routes storage/deposit/withdraw commands to the physical warehouse inventory and migrates legacy resources on demand.
- Lumberjack recovery now attempts delivery when a safe tree work position cannot be found.
