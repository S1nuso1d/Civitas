Civitas Alpha 0.43.1 — Building History
Target: Minecraft Java Edition 1.21.1 + Forge 52.1.20 + Java 21

Implemented in source:
- Per-building journal with a 24-event cap, keyed by building type and origin coordinates.
- NBT save/load for the journal; existing worlds without the new tag keep their existing building records and load with empty histories.
- Construction started/completed/cancelled, upgrades, repairs, direct damage, and weather wear state transitions are recorded.
- Construction requester names and builder villager names are stored in journal entries.
- Buildings tab now shows material tier, wear, remaining strength, construction day when known, and the two latest events for the selected building.
- Building events also appear in the existing settlement recent-events feed.
- Network protocol increased from 8 to 9 for the updated snapshot.

Validation:
- Changes are committed to GitHub but have not been built in this session.
- Run Gradle build/tests locally. In-game test should include loading an existing world, placing a new structure, upgrading it, saving/reloading, and checking that history persists.
