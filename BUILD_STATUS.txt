Civitas Alpha 0.21.0 — Neighbor Civilizations
Target: Minecraft Java Edition 1.21.1 + Forge 52.1.20 + Java 21

Added:
- Persistent profiles for neighbouring civilizations linked to trade partners.
- Bounded daily simulation of population, food, timber, stone, iron, territory and stability.
- Diplomacy commands: /civitas diplomacy; /civitas diplomacy stance <index> <neutral|allied|rival|war>.
- War suspends caravan selection for civilizations at war.
- NBT persistence and migration from existing 0.20.x saves.
- Unit tests for persistence, diplomacy/trade eligibility and bounded simulation.

Validation:
- Exact commit must pass GitHub Actions compile, tests and JAR packaging.
- Manual in-game testing is still required, including save/load, diplomacy commands and caravan behavior.
