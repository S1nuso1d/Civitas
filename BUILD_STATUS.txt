Civitas Alpha 0.3.1 — build status
Target: Minecraft Java Edition 1.21.1 + Forge 52.1.20 + Java 21

Current implementation:
- Persistent 27-slot physical warehouse with block-entity inventory.
- Server menu and client screen with synchronized slots and Shift-click transfer.
- First-join starter village generation in the Overworld: four small houses, beds, work-site blocks, paths, lighting, bell and four vanilla villagers.
- Starter warehouse supplies: oak logs, bread, wheat seeds, cobblestone, torches and saplings.
- Village coordinates and generated flag are persisted in CivitasSavedData; village is not regenerated on each login.
- First-time players are moved to the village; respawning players are returned to the Overworld village.
- If no settlement exists, one is founded at the village center and the first player becomes its owner.
- The old virtual resource commands remain separate from physical slots and still need unification.

Validation:

- Alpha 0.3.1 includes new village-generation code. Check the latest GitHub Actions run before distributing the JAR.
- No manual in-game launch or persistence test is claimed.
