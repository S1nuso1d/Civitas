Civitas Alpha 0.3.0 — build status
Target: Minecraft Java Edition 1.21.1 + Forge 52.1.20 + Java 21

Current implementation:
- Registered a block entity for the Settlement Warehouse.
- Added a 27-slot container with NBT persistence.
- Added a server menu and client screen with normal slot synchronization and Shift-click transfer.
- Warehouse interaction checks settlement ownership or operator permissions.
- Added migration of legacy virtual resources into free physical slots; only the amount actually inserted is removed from SavedData.
- Kept Alpha 0.2 commands for compatibility. The old virtual-store commands do not yet directly operate on physical warehouse slots.

Validation:
- Alpha 0.2.7 CI build succeeded on commit b593e4f8b79a59fd9fdce96160ead41bc69fe47.
- Alpha 0.3.0 Gradle build succeeded on commit 9798485879cce462cab2d7d52beb72bede929411 (GitHub Actions run 63); artifact civitas-0.3.0-forge-1.21.1 was uploaded.
- The compile result does not confirm that the mod has been manually launched in Minecraft. Persistence, owner permissions, Shift-click, legacy migration and multiplayer still need in-game testing.

Build locally:
1. Use 64-bit Java 21.
2. Run build.bat or .\tools\gradle-run.ps1 build from the project root.
3. Expected JAR after successful compilation: build/libs/civitas-0.3.0.jar.
4. Install only one Civitas JAR into the mods folder of Minecraft 1.21.1 + Forge 52.1.20.

Required manual tests after compilation:
- Place a warehouse and open it as settlement owner.
- Confirm a non-owner cannot open it.
- Move stacks both ways, including Shift-click.
- Close/reopen the GUI and verify slot contents.
- Exit and restart the world and verify contents.
- Fill the warehouse and verify no items disappear.
- Test an existing Alpha 0.2 world with virtual resources and confirm migration.
- Remove the warehouse and check expected item-drop behaviour.
