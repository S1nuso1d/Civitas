Civitas Alpha 0.24.0 — Diplomacy Has Economic Consequences
Target: Minecraft Java Edition 1.21.1 + Forge 52.1.20 + Java 21

Added:
- Alliance improves daily food reserves and stability and supports faster territorial expansion.
- Rivalry reduces stability and may consume timber in larger territories.
- War reduces stability and food reserves and consumes timber and iron under defined conditions.
- Diplomatic consequences are applied only in bounded daily simulation steps.
- Added unit coverage comparing the same neighbor profile under alliance and war.

Validation:
- GitHub Actions build/test/JAR packaging must be confirmed for the exact release commit.
- Manual in-game balance and multiplayer checks have not been performed here.
