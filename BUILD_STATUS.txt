Civitas Alpha 0.32.0 — Living Settlement
Target: Minecraft Java Edition 1.21.1 + Forge 52.1.20 + Java 21

Added:
- Responsive settlement UI now includes a Buildings tab and an achievement-tree tab.
- Building list displays stable 1-based indices and cabin upgrade levels.
- Owner-only /civitas buildings upgrade <index> upgrades registered cabins to level 2 or 3.
- Level 2 adds a porch, fence railings and lantern; level 3 adds a brick chimney and lanterns.
- Upgrade materials are withdrawn from free warehouse stock only; resources reserved by construction orders are not available.
- Building upgrade metadata (level and rotation) is persisted. Existing world data defaults to level 1 and rotation 0.
- Upgrade placement is prevalidated and has a rollback path for upgrade blocks and materials.
- Construction workers perform a visible main-hand swing while work progress advances.
- Added tests for house upgrade footprint, unique positions and invalid parameters.

Known limitations:
- Achievement unlocks are derived from saved settlement state and shown in the UI; this release does not add a separate claimable reward system.
- Resident behavior improvements are incremental: this release adds visible construction work animation, not a full daily schedule or needs simulation.
- Fire/fluid spread, mob griefing and third-party world changes are not comprehensively protected.
- The exact release has not been verified with a local Gradle build, tests or manual Minecraft play.

Validation:
- Run build and test tasks, inspect build/libs, then manually verify upgrades, persistence and UI in a disposable world before distributing a JAR.
