Civitas Alpha 0.36.0 — Achievement Progress
Target: Minecraft Java Edition 1.21.1 + Forge 52.1.20 + Java 21

Implemented in source:
- Settlement UI includes Buildings and Achievements tabs. Buildings supports paging, displays registered indices and cabin levels, and shows upgrade costs.
- Achievement tree presents 21 milestone conditions across eight development areas. Stable IDs and first-unlock world days are persisted and sent through protocol version 8. Unlocked milestones show their first-unlock day; locked milestones show a percentage calculated from current settlement stats. Rewards and prerequisite-gated unlocks are not implemented.
- Registered Civitas cabins can be upgraded to level 2 or 3 through the owner-only /civitas buildings upgrade <index> command or the Buildings tab.
- Level 2 adds a porch with slabs, supported fence railings, stairs and lantern. Level 3 adds a brick chimney through the roof.
- Building records persist upgrade level and rotation; old saves default to level 1 and rotation 0.
- Upgrade validation checks claimed chunks, settlement influence, block occupancy, fluids and loaded chunks. Free warehouse stock is used, not reserved construction materials.
- Builders face the worksite and swing while working; lumberjacks visibly chop; farmers use a timed harvest cycle before consuming a seed.
- Added automated tests for house upgrade blueprint geometry and invalid parameters.

Known limitations:
- The starter-village houses are not yet registered as upgradeable Civitas buildings; the upgrade system currently targets registered cabins built through Civitas construction.
- Achievement conditions are checked every 200 overworld ticks (10 seconds) while the settlement owner is online, even with the dashboard closed. The scan currently reuses the authoritative snapshot builder and therefore refreshes the client snapshot periodically. No rewards or prerequisite-gated unlocks yet.
- Full daily resident schedules, social behavior, rest and happiness are not implemented.
- Fire/fluid spread, mob griefing and third-party world changes are not comprehensively protected.

Validation:
- No local build, test execution or in-game verification is confirmed for this exact release.
- Run Gradle build and test tasks, inspect build/libs, then manually test upgrade persistence and block/resource rollback in a disposable world before distributing a JAR.
