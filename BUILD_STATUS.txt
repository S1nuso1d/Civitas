Civitas Alpha 0.32.0 — Achievement Branches & Dashboard Improvements
Target: Minecraft Java Edition 1.21.1 + Forge 52.1.20 + Java 21

Included:
- Achievement dashboard reorganized into a scrollable tree with nine named branches.
- Twenty-one milestone conditions cover founding, population, housing, crafts, construction, economy, trade/resource trends, territory, worker assignment and development.
- Previous/next navigation and completed/pending visual states.
- Milestones are computed from the server-provided settlement snapshot.

Known limitations:
- Achievement completion is derived from current state and is not individually persisted.
- Milestone rewards and prerequisite-gated progression are not implemented yet.
- Resident behavior, house models and house upgrade effects have not been changed in this release.
- No build, unit test or in-game verification has been confirmed for this exact commit.

Validation:
- Run the Gradle build and test tasks and inspect build/libs before distributing a JAR.
