Civitas Alpha 0.31.0 — Construction Integrity Checks
Target: Minecraft Java Edition 1.21.1 + Forge 52.1.20 + Java 21

Included territory and construction protections:
- Non-owners cannot break/place blocks or right-click blocks in claimed overworld chunks; warning messages are rate-limited.
- Explosions cannot remove blocks inside claimed overworld chunks.
- Manual and automatic building orders validate the complete rotated footprint against territory influence and claimed chunks before resources are reserved or replaceable vegetation is cleared.
- Every construction layer rechecks that the complete plot remains inside the settlement's influence and claimed chunks.
- Rotated clearance dimensions match the rotated footprint.

Added automated blueprint regression coverage:
- Checks every building type, layer, and supported rotation for duplicate positions and footprint bounds.
- Checks that 360° normalizes to 0° and 450° normalizes to 90°.

Known limitations:
- Fire/fluid spread, mob griefing, natural updates, and third-party mod changes are not comprehensively prevented.
- Rival territory ownership and claim-conflict resolution are not implemented.
- No local build, test execution, or manual in-game test has been confirmed for this exact commit.

Validation:
- Run the Gradle build and test tasks and inspect build/libs before distributing a JAR.
