Civitas Alpha 0.22.0 — Diplomacy GUI
Target: Minecraft Java Edition 1.21.1 + Forge 52.1.20 + Java 21

Added:
- Vanilla-style diplomacy screen opened from the settlement dashboard.
- Paginated list of neighbouring civilizations with population, territory, food, stability and reputation.
- Direct selection of neutral, allied, rival and war stances.
- Server-authoritative packet validation by civilization UUID and settlement ownership.
- Alliance requires trade reputation of at least 60; war blocks new caravans from that civilization.
- Network protocol version 4.

Validation:
- GitHub Actions compile, tests and JAR packaging must be checked for the exact release commit.
- Manual in-game and multiplayer testing has not been performed in this environment.
