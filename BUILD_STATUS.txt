Civitas Alpha 0.12.0 — build status
Target: Minecraft Java Edition 1.21.1 + Forge 52.1.20 + Java 21

New in 0.12.0:
- Multiple villagers can hold the builder role at the same time.
- Each builder keeps a persistent target site in entity data.
- Builders are assigned to distinct queued orders so several constructions can progress concurrently.
- Stale assignments are released after the corresponding queued order disappears.

Included foundation:
- Central building definition registry.
- Forge SimpleChannel snapshot/action packets.
- Responsive Overview / Residents / Construction / Storage dashboard.
- JUnit checks for building registry metadata and material costs.

Validation:
- GitHub Actions build and test status must pass on the final commit before release.
- Manual in-game verification of multiple concurrent builders is not available in this environment.
