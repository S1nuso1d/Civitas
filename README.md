# Civitas — Alpha 0.11.0 (Forge 1.21.1)

Civitas — модификация Minecraft Java Edition о развитии поселения от деревни к цивилизации. Главный принцип: рядом с игроком жители работают физически, строят настоящие здания и используют реальный склад; стратегические системы будут постепенно расширяться.

## Что есть в Alpha 0.11.0

- При первом входе создаётся стартовая деревня в Надземном мире, а игрок появляется рядом с ней. Координаты деревни сохраняются.
- Кодекс цивилизации открывает ванильную по стилю панель управления с вкладками «Обзор», «Жители», «Стройка» и «Склад». Панель адаптирует размеры к окну игры.
- Снимок состояния приходит с сервера и обновляется примерно раз в две секунды, пока панель открыта.
- Физический склад имеет 27 слотов. Команды склада и действия из панели используют один инвентарь.
- Лесоруб назначается обычному жителю Minecraft, ищет дерево, рубит брёвна, переносит груз и пытается доставить его на склад.
- Строителю можно поручить возведение домов, ферм и мастерских послойно. Очередь и прогресс сохраняются в данных мира.
- Стоимость, отображаемое имя, размеры и число слоёв построек задаются единым реестром `BuildingDefinition`.
- Сервер проверяет владение поселением, наличие ресурсов, тип здания и параметры действий. Клиент не изменяет состояние поселения напрямую.

## Платформа

- Minecraft Java Edition 1.21.1
- Minecraft Forge 52.1.20
- Java JDK 21 x64
- Gradle 8.8 / ForgeGradle 6.x

## Сборка на Windows

1. Установи JDK 21 и проверь `java -version`.
2. Скачай ZIP репозитория и полностью распакуй его.
3. Запусти `build.bat` или в PowerShell из корня проекта выполни:

   ```powershell
   .\tools\gradle-run.ps1 build
   ```

4. После `BUILD SUCCESSFUL` ожидаемый JAR: `build\libs\civitas-0.11.0.jar`.

## Установка в TLauncher

1. Закрой Minecraft.
2. Сделай резервную копию мира, особенно если устанавливаешь мод в существующее сохранение.
3. В папке `mods` выбранного профиля оставь только один JAR Civitas.
4. Запусти Minecraft Java 1.21.1 с Forge 52.1.20.
5. Сначала проверь мод в отдельном тестовом мире. Стартовая деревня меняет блоки рядом с точкой появления.

Открыть панель управления можно предметом «Кодекс цивилизации». В интерфейсе используйте вкладки для просмотра сводки, жителей, очереди строительства и физического склада.

## Что ещё требует проверки или развития

- Текущая версия — рабочий прототип, а не завершённая симуляция большой цивилизации.
- Поведение строителей, лесоруба, сохранение и загрузку мира нужно проверить вручную в Minecraft.
- Система нескольких поселений, выделенная экономика, отношения между цивилизациями, торговля, армии и дальняя абстрактная симуляция ещё не реализованы.
- Система отмены пока возвращает полный комплект ресурсов только для заказа, который ещё не начал строиться. Частичный возврат за начатые работы требует отдельной модели резервирования и учёта вложенных материалов.
