# Civitas — Alpha 0.2.5 (Forge 1.21.1)

Civitas — модификация для Minecraft Java Edition о развитии поселения от небольшой деревни до цивилизации. Цель проекта — стратегическое управление, реальные рабочие процессы жителей, строительство, торговля и конкурирующие государства.

> **Статус Alpha 0.2.5:** есть сохраняемая модель поселения, виртуальный склад и GUI, открываемый через Кодекс цивилизации. Из панели можно основать/переименовать поселение, посмотреть состояние и склад, сдать предметы из руки или забрать ресурсы. Ответы сервера пока выводятся в игровой чат; синхронизированного информационного экрана, физического склада-блока, рабочих и автоматической генерации деревни ещё нет.

## Версии и инструменты

- Minecraft Java Edition **1.21.1**
- Minecraft Forge **52.1.20** (для Forge 1.21.1)
- Java **21** (64 bit)
- ForgeGradle 6.x / Gradle 8.8
- Язык: Java

Официальная документация Forge для ветки 1.21.x требует JDK 21 и рекомендует собирать мод через Gradle. Сборка готового JAR должна находиться в `build/libs/`.

## Установка готового мода в TLauncher

1. Убедись, что в лаунчере установлен и выбран **Minecraft 1.21.1 — Forge**. Профили Fabric, OptiFine и чистая версия игры не подходят.
2. Нужна Java 21 x64. В настройках лаунчера выбери Java 21, если лаунчер позволяет указывать Java отдельно.
3. Получи JAR после сборки — файл `build/libs/civitas-0.2.5.jar`. ZIP с исходниками не является файлом мода.
4. В TLauncher открой папку игры выбранной Forge-сборки. Обычно это `%appdata%\.minecraft`; если у профиля настроена отдельная игровая папка, используй именно её.
5. Открой или создай внутри папку `mods` и скопируй туда `civitas-0.2.5.jar`.
6. Запусти именно профиль Forge 1.21.1. В меню Mods должен появиться **Civitas**.
7. Лучше проверь мод в новом тестовом мире. Уже существующий мир не должен пострадать, но на время тестирования сделай резервную копию сохранения.

## Сборка на Windows

### Самый простой способ

1. Установи 64-битный JDK 21. Проверь в PowerShell:

   ```powershell
   java -version
   ```

   В выводе должна быть версия 21.

2. Распакуй ZIP проекта в простую папку, например `C:\Projects\Civitas`.
3. Дважды щёлкни `build.bat`. При первом запуске потребуется доступ к интернету: скрипт скачает Gradle в `%LOCALAPPDATA%\CivitasBuildTools`, затем Gradle загрузит библиотеки Minecraft/Forge.
4. После успешного завершения возьми `build\libs\civitas-0.2.5.jar` и установи его по инструкции выше.

### Команды в PowerShell

Выполняй их из папки `Civitas`:

```powershell
# Собрать JAR
.\tools\gradle-run.ps1 build

# Запустить отдельный тестовый клиент для разработки
.\tools\gradle-run.ps1 runClient

# Проверить доступные задачи Gradle
.\tools\gradle-run.ps1 tasks
```

Для проверки можно открыть проект в IntelliJ IDEA как Gradle-проект и выбрать JDK 21 в настройках Gradle.

## Команды внутри игры

После запуска мира открой чат и введи:

```text
/civitas help
/civitas found Моя деревня
/civitas status
/civitas storage
```

Чтобы положить обычные предметы на склад, держи их в **основной руке**. Не сдавай зачарованные, повреждённые, переименованные или иным образом модифицированные предметы — текущая модель склада предназначена только для обычных ресурсов. Например, если в руке 16 дубовых брёвен:

```text
/civitas deposit 16
/civitas storage
/civitas withdraw minecraft:oak_log 8
```

Команды работают на стороне сервера; данные поселения сохраняются вместе с миром. В текущей версии на мир поддерживается одно поселение. Первое создание поселения фиксирует его центр в текущей позиции игрока — физическая генерация деревни пока не реализована.

## План следующих этапов

1. Реальный блок склада и экран управления поселением.
2. Жители-работники: лесоруб, поиск деревьев, путь, добыча и доставка предметов.
3. Система задач и постепенное строительство зданий из блоков.
4. Стратегический режим сверху и прокладка дорог.
5. Экономика, торговля, конкурирующие цивилизации, армия и дипломатия.

## Статус проверки Alpha 0.2.5

Версия 0.2.2 добавила `pack.mcmeta` с `pack_format: 34`, соответствующим формату ресурсов Minecraft 1.21–1.21.1. Версия 0.2.3 исправляет запуск Windows-скриптов: используются относительные пути, CRLF-переносы строк и ASCII-сообщения. Архив, JSON и скрипты проверены статически, однако фактическую компиляцию ForgeGradle и запуск Minecraft нужно подтвердить на Windows. Запусти `build.bat` и установи JAR версии 0.2.5. Не копируй ZIP исходников в папку `mods`.


## Alpha 0.2.5 — расширенная панель управления

Используйте Кодекс цивилизации, чтобы открыть панель управления. Из интерфейса доступны основание и переименование поселения, просмотр состояния и склада, сдача предметов из основной руки и получение ресурсов со склада. Для склада можно указать ID предмета и количество. Сервер по-прежнему проверяет владельца, наличие ресурсов и допустимые количества; ответы пока отображаются в игровом чате. Команды остаются доступными для диагностики, но для обычных действий использовать консоль не требуется.

Сборка теперь также проверяется автоматическим workflow GitHub Actions при каждом push и pull request. Результат сборки должен быть подтверждён в разделе Actions репозитория.
