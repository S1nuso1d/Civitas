# Civitas — Alpha 0.10.0 (Forge 1.21.1)

Civitas — модификация Minecraft Java Edition о развитии поселения от деревни до цивилизации. Игрок начинает в поселении, управляет ресурсами и постепенно открывает новые возможности. Долгосрочная цель — физически работающие жители, строительство, экономика и соперничающие цивилизации.

## Что добавлено в Alpha 0.5.0

- Лесоруба можно приостанавливать и возобновлять из панели управления.
- Снять профессию можно только после доставки груза, чтобы не потерять переносимые брёвна.
- Список жителей показывает состояние задачи и препятствия: отсутствие деревьев, склада или безопасного места, а также заполненный склад.

## Что добавлено в Alpha 0.4.2

- В панели управления появились действия «Жители и профессии» и «Назначить лесоруба».
- Команда `/civitas workers` показывает жителей в окрестностях поселения и их назначенные роли.
- Команда `/civitas worker lumberjack` назначает ближайшего жителя лесорубом, снимая эту роль с остальных жителей рядом с деревней.

- `/civitas storage`, `/civitas deposit` и `/civitas withdraw` теперь работают с тем же физическим складом, что и GUI.
- Перед переносом предметов команды проверяют свободное место и наличие нужного количества; ресурсы из старого виртуального склада переносятся в физический при обращении.
- Лесоруб пытается доставить уже собранные брёвна, если не находит безопасное место для рубки.

- При первом входе в мир Civitas создаёт стартовую деревню в Надземном мире и переносит туда игрока.
- Положение деревни сохраняется в данных мира, поэтому она не строится повторно при каждом входе.
- При смерти в любом измерении игрок возвращается в стартовую деревню.
- В деревне четыре небольших дома, кровати, рабочие блоки, дорожки, освещение, колокол и четыре обычных жителя Minecraft.
- В центральном складе есть стартовые запасы: брёвна, хлеб, семена, булыжник, факелы и саженцы.
- Один житель назначается лесорубом: ищет ближайшие брёвна деревьев, идёт к ним, тратит время на рубку, переносит до восьми брёвен и доставляет их в физический склад.
- Если склад заполнен или недоступен, лесоруб сохраняет груз и повторяет доставку позже. Для старых миров роль лесоруба назначается существующему жителю.
- Если поселение ещё не было основано, оно автоматически создаётся в центре стартовой деревни, а первый игрок становится управляющим.

## Alpha 0.3 — склад

Физический склад имеет 27 слотов, сохраняет инвентарь в данных блока и использует отдельное меню с переносом Shift-click. Старые виртуальные ресурсы переносятся в свободные слоты при открытии склада. Команды `/civitas deposit`, `/civitas withdraw` и `/civitas storage` используют тот же физический инвентарь, что и окно склада.

## Платформа

- Minecraft Java Edition 1.21.1
- Minecraft Forge 52.1.20
- Java JDK 21 x64
- Gradle 8.8 / ForgeGradle 6.x

## Сборка на Windows

1. Установи JDK 21 и проверь `java -version`.
2. Скачай ZIP репозитория и полностью распакуй его.
3. Запусти `build.bat` или в PowerShell из корня проекта выполни:

   ```powershell
   .\tools\gradle-run.ps1 build
   ```

4. После `BUILD SUCCESSFUL` ожидаемый JAR: `build\libs\civitas-0.7.0.jar`.

## Установка в TLauncher

1. Закрой игру.
2. В папке `mods` выбранного профиля оставь только один JAR Civitas.
3. Запусти Minecraft 1.21.1 с Forge 52.1.20.
4. Впервые проверяй мод в новом тестовом мире. Создание стартовой деревни изменяет блоки вокруг выбранного участка, поэтому для существующего мира сделай резервную копию.

## Начало игры

При первом входе деревня и поселение создаются автоматически. Кодекс цивилизации выдаётся игроку и открывает панель управления. Склад находится в центре деревни.

Команды:

```text
/civitas help
/civitas status
/civitas storage
```

Лесоруб — первый прототип. Назначение профессий через UI, перевозчик, строитель и общая очередь задач ещё не реализованы.

## Проверка

GitHub Actions: https://github.com/S1nuso1d/Civitas/actions

Успешная компиляция не заменяет ручной тест запуска Minecraft. Для стартовой деревни отдельно проверь новый мир, повторный вход, смерть/возрождение, склад и существующий мир с уже основанным поселением.


### Alpha 0.8.0 — builders
Assign a resident as builder with `/civitas worker builder` or the in-game settlement panel. The builder walks to the next queued construction site and advances it only when nearby. Without a builder, queued construction waits. Check progress with `/civitas construction`.


## Alpha 0.9.0 — обновлённый интерфейс
Панель управления переработана в стиле ванильного Minecraft: пиксельные рамки, иконки реальных предметов, отдельные разделы для поселения, склада, жителей и строительства. Окно склада приведено к визуальному стилю инвентаря Minecraft. Сборка CI публикует артефакт `civitas-0.9.0-forge-1.21.1`.


## Alpha 0.9.1 — отмена заказа строительства

- Добавлена команда `/civitas construction cancel` и кнопка в панели управления.
- Отменяется только первый заказ очереди, если строитель ещё не уложил ни одного слоя. Полный комплект материалов возвращается игроку; при заполненном инвентаре предметы выпадают рядом.
- Начатый заказ нельзя отменить: это предотвращает потерю материалов и оставленные частично построенные здания.
- GitHub Actions проверяет компиляцию; ручная проверка в Minecraft по-прежнему необходима.


## Alpha 0.9.2 — предпросмотр строительства

- Clicking a building once selects it and displays the required materials in the management panel without sending a build command.
- Clicking the same building again confirms the order and sends the command that charges materials and adds the order to the queue.
- Selecting a different building replaces the pending selection, reducing accidental resource spending.
- Build costs are currently shown as a fixed UI preview; server-side warehouse validation remains authoritative.


## Alpha 0.9.3 — выбор заказа для отмены

- Added `/civitas construction cancel <номер>`; the number follows the current queue order shown by `/civitas construction`.
- The dashboard now accepts an order number for cancellation rather than only targeting the first order.
- Only orders with zero construction progress can be cancelled. The original material set is refunded; begun orders remain protected.


## Alpha 0.10.0 — сводка поселения

Добавлена команда `/civitas overview`: единая сводка выводит число жителей рядом с поселением, распределение ролей, число зарегистрированных домов/ферм/мастерских, очередь строительства и заполненность физического склада. Если склад заполнен или в очереди есть строительство без строителя, сводка показывает предупреждение. Данные рассчитываются на сервере; это промежуточный шаг перед сетевой синхронизацией полноценного интерфейса.
