# Civitas — Alpha 0.3.0 (Forge 1.21.1)

Civitas — модификация Minecraft Java Edition о развитии поселения от деревни до цивилизации. Долгосрочная цель — физически работающие жители, строительство, экономика и соперничающие цивилизации. Рядом с игроком действия будут происходить в мире, а дальние регионы будут рассчитываться упрощённо.

## Текущий статус

**Alpha 0.3.0 находится в разработке.** Базовая Alpha 0.2.7 содержит сохраняемые данные одного поселения, Кодекс цивилизации, команды и виртуальный склад. В Alpha 0.3.0 начата реализация физического склада с 27 слотами, сохранением инвентаря в данных блока и отдельным синхронизируемым экраном. Добавлена миграция старых виртуальных ресурсов в свободные слоты физического склада.

Сборка Gradle для Alpha 0.3.0 успешно завершилась в GitHub Actions (коммит `9798485879cce462cab2d7d52beb72bede929411`); артефакт опубликован. Это подтверждает компиляцию, но не заменяет ручной запуск Minecraft и проверку сохранения предметов после перезапуска мира.

## Платформа

- Gradle 8.8 / ForgeGradle 6.x
- Java

## Сборка на Windows

1. Установи JDK 21 и проверь командой `java -version`.
2. Скачай ZIP репозитория и полностью распакуй его в отдельную папку.
3. Запусти `build.bat` или выполни в PowerShell из корня проекта:

   ```powershell
   .\tools\gradle-run.ps1 build
   ```

4. После сообщения `BUILD SUCCESSFUL` ожидаемый JAR: `build\libs\civitas-0.3.0.jar`.

## Установка в TLauncher

1. Закрой игру.
2. В папке `mods` выбранного профиля установи один JAR Civitas, убрав предыдущие версии.
3. Запусти Minecraft 1.21.1 с Forge 52.1.20.
4. Проверь мод сначала в новом тестовом мире и сделай резервную копию важного сохранения.

## Начало игры

В чате:

```text
/civitas help
/civitas found Моя деревня
/civitas status
/civitas storage
```

Кодекс цивилизации открывает прежнюю панель управления. Блок «Склад поселения» находится во вкладке «Функциональные блоки». Использовать его могут управляющий поселением и администратор.

В Alpha 0.3.0 виртуальное хранилище старой версии постепенно переносится в свободные слоты физического склада при его открытии. Если предметы не помещаются или ID предмета больше не существует, остаток не удаляется из старых данных. Команды `/civitas deposit` и `/civitas withdraw` пока относятся к старому виртуальному хранилищу; они не управляют слотами физического контейнера.
