# Civitas — Alpha 0.14.0 (Forge 1.21.1)

Civitas — модификация Minecraft Java Edition о развитии поселения от деревни к цивилизации. Жители физически работают и строят настоящие здания, а склад и очередь заказов образуют основу локальной экономики.

## Что добавлено в Alpha 0.14.0

- Для каждого здания введена отдельная смета материалов по слоям: дом, ферма и мастерская расходуют разные ресурсы на конкретных этапах.
- Смета проверяется автоматически: сумма всех этапов обязана совпадать с полной стоимостью здания, иначе некорректный план не применяется.
- При постановке заказа смета сохраняется вместе с резервом в данных мира. Изменение будущей версии мода не должно задним числом менять расчёт отмены уже начатого заказа.
- При отмене возвращается стоимость только ещё не построенных слоёв. Например, материалы фундамента дома уже относятся к завершённому этапу, а ресурсы крыши остаются к возврату до начала соответствующего слоя.
- Старые заказы без послойной сметы сохраняют совместимость и используют прежний пропорциональный расчёт.
- Добавлены JUnit-тесты для точных сумм слоёв, возвратов по этапам, неизменяемости сметы и поддержки старых заказов.

**Важно:** сейчас материалы списываются со склада целиком при постановке заказа; послойная смета определяет, какая часть считается использованной и что возвращается при отмене. Физическое списание из склада непосредственно по мере работы строителя — отдельный будущий этап.

## Уже есть в предыдущих версиях

- Стартовая деревня в Надземном мире и сохранение её координат.
- Панель управления в ванильном стиле с вкладками «Обзор», «Жители», «Стройка» и «Склад».
- Серверная синхронизация снимка поселения и типизированные действия через Forge `SimpleChannel`.
- Физический склад на 27 слотов; команды управления ресурсами используют тот же инвентарь.
- Лесоруб и несколько строителей, каждый из которых сохраняет цель работы; разные строительные заказы могут продвигаться параллельно.
- Единый реестр зданий `BuildingDefinition` с именами, затратами, габаритами и количеством слоёв.

## Платформа

- Minecraft Java Edition 1.21.1
- Minecraft Forge 52.1.20
- Java JDK 21 x64
- Gradle 8.8 / ForgeGradle 6.x

## Сборка на Windows

1. Установи JDK 21 и проверь `java -version`.
2. Скачай ZIP репозитория и полностью распакуй его.
3. Запусти `build.bat` или в PowerShell из корня проекта выполни:

   ```powershell
   .\tools\gradle-run.ps1 build
   ```

4. После `BUILD SUCCESSFUL` ожидаемый JAR: `build\libs\civitas-0.13.0.jar`.

## Установка в TLauncher

1. Закрой игру и сделай резервную копию мира.
2. Удали старый JAR Civitas из папки `mods`, оставив только одну версию.
3. Скопируй новый JAR в папку `mods` профиля Minecraft Java 1.21.1 с Forge 52.1.20.
4. Сначала проверь новую функцию в отдельном тестовом мире: начни строительство, дождись нескольких слоёв и отмени заказ.

## Ограничения прототипа

- Сборка и автоматические тесты проверяются CI; ручной запуск Minecraft не выполнялся в этой среде.
- Разборка при отмене удаляет только те блоки, тип которых совпадает с шаблоном Civitas. Если игрок заменил блок другим типом, этот блок сохраняется, но может остаться вне зарегистрированной постройки.
- Послойная смета отражает этапы строительства, но пока не является точным списком блоков чертежа. Материалы резервируются списанием со склада при постановке заказа.
- Процедурные чертежи, несколько поселений, торговля, дипломатия, армии и дальняя симуляция цивилизаций ещё предстоит реализовать.

GitHub Actions: https://github.com/S1nuso1d/Civitas/actions

Для ручной проверки в тестовом мире проверь отмену до первого слоя, после одного слоя и почти перед завершением; полностью заполненный инвентарь игрока; незагруженный чанк; сохранение мира после перезапуска.
