# Civitas — Alpha 0.4.1 (Forge 1.21.1)

Civitas — модификация Minecraft Java Edition о развитии поселения от деревни до цивилизации. Игрок начинает в поселении, управляет ресурсами и постепенно открывает новые возможности. Долгосрочная цель — физически работающие жители, строительство, экономика и соперничающие цивилизации.

## Что добавлено в Alpha 0.4.1

- `/civitas storage`, `/civitas deposit` и `/civitas withdraw` теперь работают с тем же физическим складом, что и GUI.
- Перед переносом предметов команды проверяют свободное место и наличие нужного количества; ресурсы из старого виртуального склада переносятся в физический при обращении.
- Лесоруб пытается доставить уже собранные брёвна, если не находит безопасное место для рубки.

- При первом входе в мир Civitas создаёт стартовую деревню в Надземном мире и переносит туда игрока.
- Положение деревни сохраняется в данных мира, поэтому она не строится повторно при каждом входе.
- При смерти в любом измерении игрок возвращается в стартовую деревню.
- В деревне четыре небольших дома, кровати, рабочие блоки, дорожки, освещение, колокол и четыре обычных жителя Minecraft.
- В центральном складе есть стартовые запасы: брёвна, хлеб, семена, булыжник, факелы и саженцы.
- Один житель назначается лесорубом: ищет ближайшие брёвна деревьев, идёт к ним, тратит время на рубку, переносит до восьми брёвен и доставляет их в физический склад.
- Если склад заполнен или недоступен, лесоруб сохраняет груз и повторяет доставку позже. Для старых миров роль лесоруба назначается существующему жителю.
- Если поселение ещё не было основано, оно автоматически создаётся в центре стартовой деревни, а первый игрок становится управляющим.

## Alpha 0.3 — склад

Физический склад имеет 27 слотов, сохраняет инвентарь в данных блока и использует отдельное меню с переносом Shift-click. Старые виртуальные ресурсы переносятся в свободные слоты при открытии склада. Команды `/civitas deposit`, `/civitas withdraw` и `/civitas storage` используют тот же физический инвентарь, что и окно склада.

## Платформа

- Minecraft Java Edition 1.21.1
- Minecraft Forge 52.1.20
- Java JDK 21 x64
- Gradle 8.8 / ForgeGradle 6.x

## Сборка на Windows

1. Установи JDK 21 и проверь `java -version`.
2. Скачай ZIP репозитория и полностью распакуй его.
3. Запусти `build.bat` или в PowerShell из корня проекта выполни:

   ```powershell
   .\tools\gradle-run.ps1 build
   ```

4. После `BUILD SUCCESSFUL` ожидаемый JAR: `build\libs\civitas-0.4.1.jar`.

## Установка в TLauncher

1. Закрой игру.
2. В папке `mods` выбранного профиля оставь только один JAR Civitas.
3. Запусти Minecraft 1.21.1 с Forge 52.1.20.
4. Впервые проверяй мод в новом тестовом мире. Создание стартовой деревни изменяет блоки вокруг выбранного участка, поэтому для существующего мира сделай резервную копию.

## Начало игры

При первом входе деревня и поселение создаются автоматически. Кодекс цивилизации выдаётся игроку и открывает панель управления. Склад находится в центре деревни.

Команды:

```text
/civitas help
/civitas status
/civitas storage
```

Лесоруб — первый прототип. Назначение профессий через UI, перевозчик, строитель и общая очередь задач ещё не реализованы.
