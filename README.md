# Civitas — Alpha 0.12.0 (Forge 1.21.1)

Civitas — модификация Minecraft Java Edition о развитии поселения от деревни к цивилизации. Жители должны физически выполнять работу, строить настоящие здания и доставлять ресурсы на реальный склад.

## Что добавлено в Alpha 0.12.0

- Можно назначить нескольких жителей строителями командой `/civitas worker builder` или соответствующей кнопкой в панели.
- Каждый строитель сохраняет цель в данных жителя и закрепляется за отдельным заказом; строители больше не перемещаются каждый тик между первой постройкой и остальными.
- Разные заказы могут продвигаться параллельно, если рядом с соответствующими площадками есть строители и чанки загружены.
- Завершённые и удалённые заказы освобождают назначения работников, чтобы строители могли брать новые задачи.
- В панели управления есть вкладки «Обзор», «Жители», «Стройка» и «Склад», снимок состояния приходит с сервера и периодически обновляется.
- Стоимость, название, габариты и количество строительных слоёв описываются единым реестром `BuildingDefinition`. Сервер проверяет ресурсы и параметры построек.
- Добавлены JUnit-проверки реестра зданий, стоимости и неизменяемости данных.

## Платформа

- Minecraft Java Edition 1.21.1
- Minecraft Forge 52.1.20
- Java JDK 21 x64
- Gradle 8.8 / ForgeGradle 6.x

## Сборка на Windows

1. Установи JDK 21 и проверь `java -version`.
2. Скачай ZIP репозитория и полностью распакуй его.
3. Запусти `build.bat` или в PowerShell из корня проекта выполни:

   ```powershell
   .\tools\gradle-run.ps1 build
   ```

4. После `BUILD SUCCESSFUL` ожидаемый JAR: `build\libs\civitas-0.12.0.jar`.

## Установка в TLauncher

1. Закрой Minecraft и сделай резервную копию мира.
2. Удали старый JAR Civitas из папки `mods`, оставив только один экземпляр.
3. Скопируй новый JAR в папку `mods` профиля с Minecraft Java 1.21.1 и Forge 52.1.20.
4. Сначала проверь новую функцию в отдельном тестовом мире. Стартовая деревня меняет блоки вокруг точки появления.

## Основные команды

```text
/civitas help
/civitas status
/civitas overview
/civitas workers
/civitas buildings
/civitas construction
/civitas storage
/civitas build cabin
/civitas build farm
/civitas build workshop
/civitas worker lumberjack
/civitas worker builder
/civitas deposit 16
/civitas withdraw minecraft:oak_log 16
```

Открой предмет «Кодекс цивилизации», чтобы перейти в панель управления. Вкладка «Стройка» позволяет выбрать тип здания и открыть очередь; на вкладке «Жители» можно назначать дополнительные роли.

## Что остаётся прототипом

- Ручная проверка запуска и поведения в Minecraft обязательна; CI проверяет только сборку и автоматические тесты.
- Построенные блоки пока ставятся по заранее заданным шаблонам, а не по полностью настраиваемым чертежам.
- Отмена доступна только для заказа, строительство которого ещё не началось; модель частичного возврата и разборки незавершённых зданий ещё предстоит разработать.
- Несколько поселений, дипломатия, торговля между цивилизациями, армии и дальняя абстрактная симуляция ещё не реализованы.

## Проверка

GitHub Actions: https://github.com/S1nuso1d/Civitas/actions

Успешная компиляция не заменяет ручной тест. В отдельном мире проверь: назначение двух строителей, два заказа в очереди, одновременный прогресс, отмену необработанного заказа и загрузку сохранения после перезапуска.
