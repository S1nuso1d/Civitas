# Civitas — Alpha 0.16.0 (Forge 1.21.1)

Civitas — модификация Minecraft Java Edition о развитии поселения от деревни к цивилизации. Жители физически работают и строят настоящие здания, а центральный склад и очередь заказов образуют основу локальной экономики.

## Что добавлено в Alpha 0.16.0

- Списание материалов очередного слоя выполняется как транзакция: перед изменением инвентаря создаётся снимок всех слотов.
- Если списание любого предмета неожиданно завершается ошибкой, исходное содержимое всех слотов восстанавливается, а блоки слоя не размещаются.
- Повреждённая или неполная смета не должна приводить к частичной оплате слоя. Предыдущие возможности Alpha 0.15.0 сохранены.

## Что добавлено в Alpha 0.15.0

- Материалы новых заказов больше не списываются целиком при постановке строительства. Полная смета резервируется логически, а предметы остаются в физическом складе до наступления нужного этапа.
- При завершении слоя со склада списываются только материалы, назначенные этому слою в смете дома, фермы или мастерской.
- При постановке новых заказов проверяется не только фактический запас, но и материалы, уже зарезервированные другими активными заказами. Один запас нельзя пообещать нескольким зданиям.
- Если игрок забрал зарезервированные материалы старым способом или склад стал недоступен, стройка останавливается до восстановления нужного запаса и не создаёт бесплатный слой.
- Команда /civitas withdraw и обычное/быстрое перемещение в интерфейсе склада защищают количество предметов, зарезервированное под стройку.
- При отмене нового заказа неиспользованные предметы остаются на центральном складе, а резерв освобождается. Материалы завершённых слоёв остаются израсходованными.
- Заказы из сохранений до 0.15.0 распознаются как оплаченные заранее: при отмене их неиспользованные материалы по старым правилам возвращаются игроку.
- В очереди /civitas construction показывается, когда заказ ждёт восстановления зарезервированных ресурсов.

## Учёт материалов

Послойная смета — это смета этапа строительства, не точный подсчёт каждого установленного блока. Для новых заказов товары хранятся на центральном складе, но резервируются в данных мира до завершения соответствующего слоя. Для перехода к следующему слою должно хватать всех активных складских резервов, поэтому один заказ не расходует ресурсы другого.



## Уже есть в предыдущих версиях

- Стартовая деревня в Надземном мире и сохранение её координат.
- Панель управления в ванильном стиле с вкладками «Обзор», «Жители», «Стройка» и «Склад».
- Серверная синхронизация снимка поселения и типизированные действия через Forge `SimpleChannel`.
- Физический склад на 27 слотов; команды управления ресурсами используют тот же инвентарь.
- Лесоруб и несколько строителей, каждый из которых сохраняет цель работы; разные строительные заказы могут продвигаться параллельно.
- Единый реестр зданий `BuildingDefinition` с именами, затратами, габаритами и количеством слоёв.

## Платформа

- Minecraft Java Edition 1.21.1
- Minecraft Forge 52.1.20
- Java JDK 21 x64
- Gradle 8.8 / ForgeGradle 6.x

## Сборка на Windows

1. Установи JDK 21 и проверь `java -version`.
2. Скачай ZIP репозитория и полностью распакуй его.
3. Запусти `build.bat` или в PowerShell из корня проекта выполни:

   ```powershell
   .\tools\gradle-run.ps1 build
   ```

4. После `BUILD SUCCESSFUL` ожидаемый JAR: `build\libs\civitas-0.16.0.jar`.

## Установка в TLauncher

1. Закрой игру и сделай резервную копию мира.
2. Удали старый JAR Civitas из папки `mods`, оставив только одну версию.
3. Скопируй новый JAR в папку `mods` профиля Minecraft Java 1.21.1 с Forge 52.1.20.
4. Сначала проверь новую функцию в отдельном тестовом мире: начни строительство, дождись нескольких слоёв и отмени заказ.

## Ограничения прототипа

- Сборка и автоматические тесты проверяются CI; ручной запуск Minecraft не выполнялся в этой среде.
- Разборка при отмене удаляет только те блоки, тип которых совпадает с шаблоном Civitas. Если игрок заменил блок другим типом, этот блок сохраняется, но может остаться вне зарегистрированной постройки.
- Послойная смета отражает этапы строительства, но пока не является точным списком каждого блока чертежа.
- Процедурные чертежи, несколько поселений, торговля, дипломатия, армии и дальняя симуляция цивилизаций ещё предстоит реализовать.
