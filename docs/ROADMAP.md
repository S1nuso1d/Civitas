# Дорожная карта Civitas

## Видение

Civitas — стратегическая модификация Minecraft, в которой игрок начинает с небольшого поселения и постепенно превращает его в цивилизацию. Мир не должен быть только набором меню: вблизи игрока жители физически перемещаются, добывают ресурсы и строят здания. Далёкие поселения работают на облегчённой симуляции, чтобы не перегружать сервер.

## Технические принципы

- Целевая платформа: Minecraft Java Edition 1.21.1, Forge 52.1.20, Java 21.
- Экономика и авторитетное состояние находятся на сервере.
- Данные мира сохраняются через SavedData; инвентари блоков — в BlockEntity.
- UI получает состояние через синхронизируемые меню и пакеты, а не путём разбора чата.
- Любая операция с ресурсами должна быть атомарной: предметы нельзя дублировать или терять при ошибке.
- ИИ работников строится как очередь задач и конечные автоматы, а не как дорогой вызов языковой модели каждый тик.
- Симуляция близких и далёких регионов использует разные уровни детализации.
- Каждый этап должен компилироваться и иметь воспроизводимый сценарий ручной проверки.

## Текущие ограничения Alpha 0.4.0

Alpha 0.4.0 добавляет стартовую деревню и прототип лесоруба, но команды `/civitas deposit`, `/civitas withdraw` и `/civitas storage` пока работают с прежним виртуальным хранилищем. При открытии физического склада запускается перенос старых ресурсов в свободные слоты; переполненный остаток остаётся в виртуальных данных. Ручной игровой тест стартовой деревни, pathfinding лесоруба, доставки ресурсов, миграции и проверка перезапуска мира ещё обязательны. Поддерживается одно поселение на мир; население пока числовое, настоящих работников, строительства, стратегической карты и соперников нет.

## Критерии приёмки каждого релиза

1. GitHub Actions завершает сборку успешно.
2. Нет известных ошибок регистрации или загрузки ресурсов.
3. Данные сохраняются после перезапуска мира.
4. Ресурсы не дублируются и не исчезают.
5. Есть пошаговый тест и актуальная инструкция установки.
6. Непроверенные игровые функции прямо обозначены как непроверенные.
