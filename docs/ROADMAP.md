# Дорожная карта Civitas

## Принципы разработки

- Целевая игровая платформа этой ветки: Minecraft Java Edition 1.21.1 + Forge 52.x, Java 21.
- Каждый этап должен иметь воспроизводимую сборку, проверяемый игровой сценарий и обновлённую инструкцию установки.
- Экономика и состояние поселений — на сервере; состояние мира сохраняется через SavedData.
- Жители рядом с игроком выполняют работу физически, далёкие цивилизации развиваются в упрощённой симуляции.
- Сначала создаём надёжный вертикальный срез и только затем расширяем масштаб.

## Текущая версия: Alpha 0.2.7

В одном мире поддерживается одно поселение. Игрок создаёт его командой `/civitas found <название>`. Фиксируются имя, владелец, координаты центра, население (начальное значение 5), уровень (1) и содержимое виртуального склада. Предметы не создаются из воздуха: сдача на склад удаляет их из инвентаря, выдача списывает их со склада.

Ограничения текущего среза: деревня сама не генерируется; жители ещё не назначаются на профессии; блок склада уже есть, но он пока не имеет отдельного контейнера со слотами и синхронизированного информационного экрана; GUI запускает серверные команды, а ответы отображаются в игровом чате; население — сохранённый параметр, а не набор реальных NPC; другие цивилизации отсутствуют.

## Критерии готовности следующего этапа

1. Сущности/блоки доступны в клиентской и серверной среде.
2. Все изменения данных корректно сохраняются после выхода и повторного входа.
3. Ресурсы не дублируются и не исчезают при повторном выполнении команд.
4. Есть короткий сценарий ручной проверки в README и инструкция установки готового JAR.
